# AI HR System Anomaly Detection

This example demonstrates a simplified AI-driven security monitor for an HR system. It processes simulated user access logs and flags anomalies such as unknown users, access outside normal working hours, or unusually broad access to multiple departments. This mimics how AI can be used to detect suspicious activity that might lead to system outages, like the ARTEX attack described in the article.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
